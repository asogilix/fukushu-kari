# ふくしゅう写真帳

参考書を撮った写真をフォルダにまとめて、忘れかけたころに見直す写真帳です。Android の Chrome を想定しています。写真、メモ、フォルダ、復習の予定と記録は、開いたブラウザの中に保存します。

## 使い方

1. **フォルダを作る**で、科目などの名前を入れます。最初からある「未分類」も使えます。
2. **取りこみ**で保存先を選び、カメラで撮るか、スマホの写真を選びます。写真はまとめて選べます。PDF は**PDF を取りこむ**の**PDF を選ぶ**から選びます。範囲に `3-10` と入れると3〜10ページ、空のままなら全ページが対象です。
3. フォルダで写真を開くと、指で広げて拡大できます。写真の題名はファイルの日時で、日時がないときは取りこんだ日時です。PDF は名前とページ番号が題名になります。メモは自動で保存され、フォルダの一覧ではメモの1行目が題名の代わりに出ます。参考用の写真は**復習しない**に切り替えられます。
4. ホームの**今の復習**を押すと、期限が来た写真が古い順で出ます。**今日このあと**には、次の朝4時までに期限が来る枚数が出ます。全体とフォルダ別を選べます。**メモを見る**で答えを確かめてから、**覚えてた**、**忘れてた**、**あとで**を選びます。
5. **設定**の**バックアップを作る**で準備し、**ファイルを保存する**で ZIP を保存します。復元は**バックアップを読みこむ**でこの ZIP を選びます。今の写真帳に追加し、同じ ID の写真やフォルダはファイルの内容で上書きします。同じ写真の復習の予定と記録も入れ替わります。

Android では、HTTPS のアドレスを Chrome で開き、ブラウザのメニューから**ホーム画面に追加**を選べます。最初に通信できる状態で開き、アプリのファイルが保存されると、次からはオフラインでも使えます。端末やアドレスを変えるときは、バックアップを保存し、新しい写真帳で読みこんでください。

## 復習のしくみ

写真を取りこんだ1時間後に、初めての見直しができます。**忘れてた**を押すと10分後にもう一度出ます。**あとで**を押すと、結果を記録せず今回の復習の列の最後に移ります。

FSRS は、いつ見直して、覚えていたかどうかをもとに、写真ごとに忘れる速さを見積もるしくみです。覚えている見こみが目標に近づくころに、次の復習を予定します。**設定**の**覚えている確率の目標**は最初は90%で、80〜95%の間で変えられます。変更は次に復習で答えたときから反映されます。写真を開くと、次の復習が見られます。覚えている見こみは、初回の復習を終えると表示されます。

日ごとの予定は朝4時に始まり、午前0時から朝4時までは前の日に数えます。1時間後や10分後の見直しは時計どおりなので、朝4時をまたぐこともあります。最初の版の写真は、更新やバックアップの読みこみ直後から、初めての復習として見直せます。

## パソコンで試す

Node.js 22.13 以降があるパソコンで、このフォルダから次を実行します。

```powershell
node tools/serve.mjs
```

ブラウザで `http://localhost:8080/` を開きます。止めるときは、コマンドを実行した画面で `Ctrl+C` を押します。

```powershell
node --test tests/*.test.js
```

## 同梱ファイルを作り直す

PDF.js 6.5.438 と ts-fsrs 5.4.2 を `vendor/` に同梱しています。オフラインでも PDF を取りこめます。パスワードで保護された PDF は対象外です。

`package.json` で指定した版が `node_modules/` にそろっていれば、次のコマンドで両方の同梱ファイルとオフライン保存の一覧を作り直せます。

```powershell
node tools/assets.mjs --with-pdf
```

## GitHub Pages に置く場合

1. `index.html`、`manifest.webmanifest`、`sw.js`、`asset-list.js`、`css/`、`js/`、`icons/`、`vendor/` を公開元の同じ階層に置きます。
2. リポジトリの設定で GitHub Pages の公開元を選びます。発行された HTTPS のアドレスを開きます。

表示名は `js/config.js` で変えられます。アプリのファイルを変更したら `node tools/assets.mjs` を実行し、ホーム画面用の設定とオフライン保存の一覧を更新します。

バックアップは圧縮なしの ZIP で、上限は約4ギガバイトです。**ファイルを保存する**を押した日を、最後のバックアップの日として表示します。
