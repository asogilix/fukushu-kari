# わすれな帳

参考書を撮った写真をフォルダにまとめて、忘れかけたころに見直す写真帳です。Android の Chrome を想定しています。写真、メモ、印、フォルダ、復習の予定と記録、せっていは、開いたブラウザの中に保存します。

## 使い方

1. **ほーむ**のフォルダ一覧には、「民法 › 総則」のようにフォルダが2段で並びます。左の矢印で中のフォルダを開いたり閉じたりでき、開閉はブラウザに保存されます。名前を押すとフォルダが開きます。「民法の中のフォルダ」のような見出しの下で、右に **›** がある行を押すと、そのフォルダに入れます。**＋ 作る**で名前と作る場所を選べます。写真はどちらの段にも入れられます。「未分類」は一覧のいちばん下にあります。
2. 写真を入れたいフォルダを開き、**ここに取りこむ**を押します。**カメラで撮る**か**スマホの写真を選ぶ**で写真を入れます。スマホの写真はまとめて選べます。**PDF を選ぶ**では、ファイルを選んだあとにページの範囲を指定できます。`3-10` なら3〜10ページ、空のままなら全ページを取りこみます。取りこみが終わると、同じフォルダで取りこんだ枚数が出ます。
3. フォルダで写真を開くと、写真のすぐ下に印とメモ欄が出ます。写真を押すと全画面で表示します。写真の題名はファイルの日時で、日時がないときは取りこんだ日時です。PDF は名前とページ番号が題名になります。メモは自動で保存され、フォルダの一覧ではメモの1行目が題名の代わりに出ます。参考用の写真は**復習しない**に切り替えられます。
4. **ほーむ**の**今の復習**で**始める**を押すと、すべてのフォルダから、期限が来た写真が古い順で出ます。フォルダを開くと**このフォルダを復習**が使えます。1段目の枚数と復習には、中のフォルダの写真も含みます。**メモを見る**で答えを確かめてから、**覚えてた**、**忘れてた**、**あとで**を選びます。
5. **せってい**の**バックアップを作る**で準備し、**ファイルを保存する**で ZIP を保存します。最後に保存した日も**せってい**で見られます。復元は**バックアップを読みこむ**でこの ZIP を選びます。今の写真帳に追加し、同じ ID の写真やフォルダはファイルの内容で上書きします。同じ写真の復習の予定と記録も入れ替わります。写真の印、一覧の並べ方としぼりこみ、取りこみ直後のメモ欄のオン・オフも保存されます。古いバックアップでは、印の記録がない写真は印なしになり、せっていの記録がなければ端末の今のせっていを引き継ぎます。2段の並びも保存され、親の記録がない古いバックアップのフォルダは1段目に入ります。

フォルダの **︙** から名前を変えられます。1段目では**この中にフォルダを作る**、2段目では**別のフォルダの中へ移す**を選べます。**フォルダを消す…**では、2段目の写真は一緒に消すか、1つ上に移すかを選びます。1段目を消すと中のフォルダも消え、写真は一緒に消すか「未分類」に移すかを選べます。「未分類」でできる操作は名前の変更です。

画面は明るい青と白で表示します。フォルダを開くと、こい青の表紙にクリーム色の復習ボタンが出ます。ほーむの復習ボタンは青、フォルダ一覧の今の復習の枚数にはオレンジを使っています。

### 写真を全画面で見る

写真を1回押すと、上の枚数表示と**×**を隠したり、もう一度出したりできます。2本指で広げたりつまんだりして、元の大きさから5倍まで変えられます。同じ場所を素早く2回押すと約2.5倍に拡大し、拡大中にもう一度2回押すと元に戻ります。拡大中は1本指で写真を動かせます。パソコンではマウスのホイールでも拡大・縮小できます。

元の大きさで左にスライドすると次の写真、右にスライドすると前の写真が出ます。パソコンでは **←** と **→** でも切り替えられます。写真は今のフォルダの一覧と同じ順番です。開いた写真がしぼりこみの対象外なら、そのフォルダの全写真を同じ並べ方で見られます。

**×**、スマホの戻る操作、パソコンの **Esc**、または元の大きさで下に引っぱって閉じます。閉じると、最後に見ていた写真の印とメモの画面に戻ります。復習中はそのときの1枚を全画面で開き、上の帯には**×**が出ます。閉じると同じ復習に戻ります。

### 印と写真の一覧

印は赤・黄・緑の丸です。写真の画面、復習の画面、取りこみ直後のメモ欄で、丸を押すたびにつけ外しできます。ついている印は色でぬりつぶされ、外すとふちだけになります。1枚に複数の印をつけられ、つけた印は一覧の写真の角にも出ます。

写真の一覧の上にある**新しい順**、**古い順**、**忘れていそうな順**、**自分の順**のどれかを押すと、その場で並べかえられます。選んでいる並べ方はこい青になります。初めは**古い順**で、**新しい順**とともに取りこんだ日時で並べます。**忘れていそうな順**は、まだ一度も答えていない写真が先、その後に覚えている見こみが低い写真から並び、復習しない写真は最後に来ます。同じ見こみなら取りこんだ日時の古い順にし、取りこんだ日時も同じなら写真の識別子の順で固定します。

**自分の順**では、フォルダごとに決めた順で写真が並びます。**しぼりこみ**を**すべて**にして写真を長押しし、好きな場所まで動かして離すと、表示中の並びをもとに順番が保存され、**自分の順**に切りかわります。あとから取りこんだ写真や別のフォルダから移した写真は、順番を決めた写真のうしろに、取りこんだ古い順で並びます。決めた順番はバックアップでも引き継げます。

**しぼりこみ**の色の丸を押すと、その色の印がついた写真を表示します。選んだ色の丸と枚数が出ます。**すべて**を押すと解除できます。並べ方としぼりこみは全フォルダ共通で端末に保存します。

### 取りこみ直後のメモ欄

**せってい**で**取りこんだ直後にメモ欄を出す**をオンにすると、カメラ、スマホの写真、PDF の取りこみが終わったあとに、写真の見本とメモ欄、印のボタンが下から出ます。複数枚のときは1枚ずつ順に出ます。**保存**でメモと印を保存し、**あとで**でその1枚をとばします。**残りはあとで**を押すと、表示中の写真から最後の写真までとばします。とばしても写真は取りこんだままで、あとから写真の画面で編集できます。初めはオフで、取りこんだ枚数だけをお知らせします。

### スマホのホーム画面に置く

Android では、HTTPS のアドレスを Chrome で開き、ブラウザのメニューから**ホーム画面に追加**を選べます。アイコンからアプリとして開くと、**せってい**の追加方法の案内は消えます。最初に通信できる状態で開き、アプリのファイルが保存されると、次からはオフラインでも使えます。端末やアドレスを変えるときは、バックアップを保存し、新しい写真帳で読みこんでください。

## 復習のしくみ

写真は取りこんだ直後から、**今の復習**に出ます。**忘れてた**を押すと10分後にもう一度出ます。復習が終わったときに忘れた写真が残っていれば、その枚数が表示されます。**あとで**を押すと、結果を記録せず今回の復習の列の最後に移ります。

FSRS は、いつ見直して、覚えていたかどうかをもとに、写真ごとに忘れる速さを見積もるしくみです。覚えている見こみが目標に近づくころに、次の復習を予定します。**せってい**の**覚えている確率の目標**は最初は90%で、80〜95%の間で変えられます。変更は次に復習で答えたときから反映されます。写真を開くと、次の復習が見られます。覚えている見こみは、初回の復習を終えると表示されます。

日ごとの予定は朝4時に始まり、午前0時から朝4時までは前の日に数えます。忘れた写真の見直しは時計どおり10分後なので、朝4時をまたぐこともあります。最初の版の写真は、更新やバックアップの読みこみ直後から、初めての復習として見直せます。

## パソコンで試す

Node.js 22.13 以降があるパソコンで、このフォルダから次を実行します。

```powershell
node tools/serve.mjs
```

ブラウザで `http://localhost:8080/` を開きます。止めるときは、コマンドを実行した画面で `Ctrl+C` を押します。

```powershell
node --test tests/*.test.js
```

## 同梱ファイルを作り直す

PDF.js 6.5.438 と ts-fsrs 5.4.2 を `vendor/` に同梱しています。オフラインでも PDF を取りこめます。パスワードで保護された PDF は対象外です。

画面の文字には Zen Maru Gothic（SIL Open Font License 1.1、`vendor/zen-maru-gothic/OFL.txt`）を使います。フォントのファイルは、よく使う字だけに減らしています。入っていない字は端末のフォントで表示します。

`package.json` で指定した版が `node_modules/` にそろっていれば、次のコマンドで両方の同梱ファイルとオフライン保存の一覧を作り直せます。

```powershell
node tools/assets.mjs --with-pdf
```

## GitHub Pages に置く場合

1. `index.html`、`manifest.webmanifest`、`sw.js`、`asset-list.js`、`css/`、`js/`、`icons/`、`vendor/` を公開元の同じ階層に置きます。
2. リポジトリの設定で GitHub Pages の公開元を選びます。発行された HTTPS のアドレスを開きます。

表示名は `js/config.js` で変えられます。アプリのファイルを変更したら `node tools/assets.mjs` を実行し、ホーム画面用の設定とオフライン保存の一覧を更新します。

バックアップは圧縮なしの ZIP で、上限は約4ギガバイトです。**ファイルを保存する**を押した日を、最後のバックアップの日として表示します。
